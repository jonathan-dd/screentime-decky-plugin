# ScreenTime — Decky-Plugin für SteamOS

**ScreenTime** Enforces regular breaks from gaming on the Steam Deck: sessions are time-limited, you’re warned before a session ends, and afterward the device goes into sleep mode until the break is over.

## Nach Plugin-Updates

Das Steam-UI behält nach einem Plugin-Update die alte Frontend-Version im Speicher. Erst ein Plugin-Reload (Decky → Plugin deaktivieren/aktivieren bzw. „Reload") oder ein Steam-Neustart lädt die neue Oberfläche — sonst laufen Buttons ins Leere.
